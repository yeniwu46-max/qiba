# 棋霸 · 网页联机版

浏览器打开即可联机：五子棋 / 黑白棋 / 围棋（9路简化）/ 国际跳棋 / 飞行棋。

支持 1v1、2v2、3 人飞行棋、道具赛、外援赛、友尽赛（真心话）、煤球五色装扮、系列局（1~5）与结算表情。

支持公开/私密房间、「世界」公开房列表、大厅聊天、观战席换位、账号登录与背包礼物。

仓库：**https://github.com/yeniwu46-max/qiba**

## 启动（本地）

```bash
cd server
npm install
npm start
```

浏览器打开：**http://127.0.0.1:3000**（页面和 WebSocket 都走本机，不必改 `web/ws-config.js`）。

再开一个浏览器窗口（或无痕模式）即可双人对战：一端创建房间，一端输入房间码加入，或从「世界」列表加入公开房。

## 玩法

| 模式 | 说明 |
|------|------|
| 1v1 | 两人对战 |
| 3人 | 飞行棋三人局 |
| 2v2 | 四人两队，同色轮流落子 |
| 道具赛 | 吞噬 / 压时 / 加悔棋等；默认各有 1 次悔棋 |
| 外援赛 | 观战加入后可代下，最多 5 步 |
| 友尽赛 | 五子棋 1v1：每局结束后赢家出题，输家真心话作答；拒答或超时扣除 3 件背包物品 |
